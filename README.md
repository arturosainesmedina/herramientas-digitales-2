## 👋 Bienvenido

Este repositorio reúne los trabajos y actividades realizados en la asignatura **Herramientas Digitales 2**.

El objetivo es mantener un espacio organizado donde se puedan consultar las actividades desarrolladas, aplicando conocimientos de lógica, algoritmos y herramientas digitales.
