con lógica algorítmica

Ejemplo práctico: retirar dinero de un cajero automático. Observa cómo se analiza una situación, se organiza una secuencia de pasos y se comprueba el resultado.

1Comprender
2Planear
3Desarrollar
4Probar

1Comprender el problema

Queremos retirar una cantidad de dinero de nuestra cuenta usando un cajero automático.

  • Entradas: tarjeta, clave personal y monto a retirar.
  • Condiciones: clave correcta, saldo suficiente y cajero con efectivo.
  • Salida: dinero entregado y saldo actualizado.
Pregúntate: ¿Cuánto dinero necesito retirar? ¿Tengo saldo suficiente?
Si necesito retirar $40, debo tener al menos $40 disponibles y el cajero debe contar con efectivo para entregar ese monto.

2Planear la solución

Antes de ejecutar la operación, organizamos los pasos y las posibles decisiones.

  • Insertar la tarjeta e ingresar la clave.
  • Seleccionar «Retiro» e indicar el monto.
  • Verificar la clave, el saldo y la disponibilidad de efectivo.
  • Si todo es correcto, autorizar el retiro.
Pregúntate: ¿Qué debe comprobar el cajero antes de entregar el dinero?
El cajero debe validar primero la clave. Luego comprueba que el monto solicitado no supere el saldo disponible y que tenga efectivo suficiente.

3Desarrollar el algoritmo

Convertimos el plan en instrucciones claras, ordenadas y con decisiones cuando sea necesario.

  • Leer la tarjeta y la clave.
  • Si la clave es correcta, solicitar el monto.
  • Si hay saldo y efectivo, entregar el dinero y actualizar la cuenta.
  • Si no se cumplen las condiciones, mostrar un mensaje y no realizar el retiro.
  • Finalizar la operación y retirar la tarjeta.
Recuerda: un algoritmo debe contemplar tanto el camino correcto como los posibles errores.
Pseudocódigo: INICIO → Validar clave → Solicitar monto → ¿Saldo suficiente? → Sí: entregar efectivo y actualizar saldo / No: mostrar mensaje → FIN.

4Analizar y probar

Probamos el procedimiento con distintos valores para revisar que las decisiones sean correctas.

  • Probar un retiro permitido.
  • Probar un monto mayor al saldo.
  • Comprobar que el saldo solo disminuya si el retiro se realiza.
  • Corregir cualquier error encontrado.
Pregúntate: ¿El cajero entrega dinero solamente cuando se cumplen las condiciones?
Con saldo de $100 y retiro de $40, el resultado esperado es entregar $40 y dejar $60. Si se solicitan $120, debe rechazar la operación y conservar el saldo de $100.
